# Phase 2 Protocol: Closed-Loop Hybrid Composition

## Question

Can the donor-free tens prototype compose autoregressively with the existing
leading and ones writers to generate complete balanced counterfactual results?

The tens prototype passed every teacher-forced diagnostic gate. This experiment
tests full three-step generation.

## Frozen components

| Position | Component | Hidden index | Scale |
|---|---|---:|---:|
| Leading | balanced-counterfactual causal adapter | 23 | 1.0 |
| Tens | rank-16 digit prototype | 27 | 1.25 |
| Ones | balanced-counterfactual causal adapter | 23 | 1.0 |

All source results, weights, basis, prototypes, dataset, and targets are
verified by SHA-256. No component is retrained or selected in this experiment.

## Deterministic hard gate

At every position, first compute the unmodified next-token argmax on the actual
closed-loop prefix. If it already equals the requested digit, apply exactly
zero delta. Otherwise apply the frozen component delta, capped at the
recipient's residual norm.

This gate is part of the deterministic controller, not a learned behavior.

## Development conditions

- untouched base;
- targeted hybrid;
- original-result identity with hard gating;
- shuffled target, norm matched;
- shuffled state, norm matched;
- random direction, norm matched.

Each condition generates all three digits autoregressively. Later components
receive the digits actually generated by earlier components.

## Frozen advancement gate

- exact target result at least 50%;
- every answer position at least 70%;
- exact advantage over every matched control at least 25 points;
- identity preservation at least 90%;
- mean relative norm at most 1.0 at every position;
- parse rate 100%.

All gates must pass to justify freezing a full donor-free implant for audit.
This iterative development run does not itself open audit.
